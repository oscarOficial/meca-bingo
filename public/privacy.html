Privacy policy

Meca Bingo website and the Meca Bingo Sync browser extension · Last updated: 23 November 2026 (extension 1.1)

Summary

Meca Bingo does not collect, sell or share personal data. There are no accounts, no cookies and no advertising. We only keep anonymous visit and usage counts (see below). Game data stays in the browsers of the people playing.

The website

  • Game data (playlist, cards, played songs, player nicknames, photos and messages) is stored only in the host's browser (localStorage and IndexedDB). Photos never leave the host's computer.
  • Players' phones connect directly to the host's browser (WebRTC). The public PeerJS signalling service is used only to introduce the two browsers; game data does not pass through it.
  • Anonymous usage statistics: the host's page sends a few anonymous counters to our server so we can see how the game is used and what to improve: that a game was created (music service, number of songs, card type and rules), that a player joined, that a prize was called and whether it was valid, how a playlist import went, and the length of a finished game. We store the day, the country Cloudflare reports and the page language. We do not store IP addresses, device ids, nicknames, playlist names or song titles, and nothing is used for advertising. Records are deleted after about 13 months.
  • Hosting: the site is served by Cloudflare. Like any web server, Cloudflare processes your IP address and browser details to deliver the pages and protect against abuse. We do not use cookies or advertising trackers. Visits are counted with Cloudflare Web Analytics, which does not use cookies, fingerprinting or cross-site tracking. Fonts and scripts are served from our own domain.
  • Connection service: to connect phones with the host, both browsers contact the PeerJS signalling server (0.peerjs.com), which sees their IP addresses for that purpose only.
  • Playlist import: when the host pastes a link to a public playlist, our server reads that public page once to get the song titles and artists, and returns them. Nothing is stored.

The Meca Bingo Sync extension

The extension is optional and only used by the host. It works only on the Amazon Music, Spotify, Deezer, YouTube Music and Apple Music web players and on the Meca Bingo website. It:

  • reads the titles and artists of a playlist the host asks to import, on the Amazon Music page open in the host's own browser;
  • reads the title and artist of the song currently playing, and sends them to the Meca Bingo page open in the same browser, so the song is marked on the bingo;
  • presses play, pause, next and previous in the music player when the host asks;
  • stores a few technical values (which tab is the music tab) in the browser's session storage, deleted when the browser closes.

The extension does not read passwords, cookies, browsing history or any other website, does not send data to any server, and does not use remote code.
